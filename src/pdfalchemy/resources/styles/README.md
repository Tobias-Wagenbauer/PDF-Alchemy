# Resources: Styles

This folder holds Qt stylesheet (`.qss`) files used to theme the application.

- `dark.qss` — the default (and currently only) theme: a modern, dark,
  black-and-shades UI with a deep purple accent. See
  [`docs/DESIGN.md`](../../../../docs/DESIGN.md) for the full design system
  this file implements, and [`ui/theme.py`](../../ui/theme.py) for how it's
  loaded and applied at startup.
