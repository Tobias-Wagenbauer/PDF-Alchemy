# Branding assets

Source artwork for the PDF Alchemy logo. These are not loaded by the app at
runtime; the app uses the derived files in
[`src/pdfalchemy/resources/icons/`](../../src/pdfalchemy/resources/icons).

| File | Purpose |
|------|---------|
| `icon.png` | Master logo (transparent, tight crop). Source for `app.png` / `app.ico` via `scripts/build_icons.py`. |
| `icon_with_spacing.png` | Original logo with extra empty space around it. |
| `icon_app.png` | iOS-style rounded-square variant, reserved for app store listings. |
